Palm Grove Estate landing page: how it works.

A single page for adverts, at palmgrove.jayleadagro.com. It has one job: turn a visitor from an advert into a lead your sales team can call. This guide covers what buyers see, where their details go, what is still a placeholder, and what to switch on before launch.

1. What a buyer sees

The page follows the content brief section by section, in its order: hero, trust badges, the opportunity, what you own, seedlings, pricing, the brochure video, the timeline, the earnings, legal safety, proof from the farm, FAQ and the final form. There is no menu, so nothing leads away from the offer.

2. Pricing and the two forms

Every call-to-action opens a form in a pop-up, already set to the right choice. A "1 Hectare" button opens with "1 Hectare" selected; "Book a Site Inspection" opens with "Site inspection" selected. If JavaScript is off, the same buttons jump to the form at the bottom of the page, so no lead is ever blocked.

3. Checking the answers

The answers are checked on the server before anything is saved. WhatsApp numbers are accepted from any country. A number without a country code is read as Nigerian (0803 123 4567). Numbers from abroad start with their code (+44, +1, +971) and are checked against that country's rules. Every number is saved in one international format, +447911123456.

Other protections

  • A hidden field catches spam bots, which are dropped silently.
  • Each address can submit at most 5 times in 10 minutes.
  • Consent (NDPR) must be ticked, with a link to the Privacy Policy.
  • Hidden fields record which advert brought the buyer: utm_source, utm_campaign, ad_id and the others.

4. Where the responses go

After the checks pass, the lead goes to the first destination that is switched on:

1. HubSpotLater, once the account exists. Not set up
2. EmailSent through Resend to the sales inbox. Use this now
3. Server logUsed only if neither is set up. The lead is lost.
Thank-you pageThe buyer always lands here, and the ad conversion fires.

Today neither HubSpot nor email is configured, so test submissions only reach the server log. Switch email on before any advert goes live.

Switching on email

  1. Create a Resend account (resend.com) and make an API key.
  2. Add the domain jayleadagro.com in Resend and put its DNS records at the domain's DNS host. Until Resend shows the domain as verified, its test sender only delivers to the Resend account owner's own email address.
  3. In Vercel, under Settings then Environment Variables, add the three variables below, then redeploy.
Variable Value
RESEND_API_KEY The re_… key from Resend. It is a secret, so never commit it.
LEAD_NOTIFY_EMAIL The sales inbox, e.g. jayleadagriestate@gmail.com. Separate several inboxes with commas.
LEAD_FROM_EMAIL Palm Grove <leads@jayleadagro.com>, set once the domain is verified.

5. After the form: thank-you and WhatsApp

Before the first advert

  1. Set the Resend variables and send yourself a test lead from the live page.
  2. Point DNS: a CNAME from palmgrove to Vercel, and add the domain in Vercel.
  3. Add the Meta Pixel and Google tag IDs, then check the conversion on /thank-you.
  4. Build every ad link with utm_source, utm_medium, utm_campaign and ad_id={{ad.id}}.
  5. Confirm two points where the brief and the main site disagree: Payment Receipt or Certificate of Allocation, and whether the hectare is available or reserved.
